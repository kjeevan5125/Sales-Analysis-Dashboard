# Sales Analysis Dashboard

An interactive sales analysis dashboard built using **Power BI and Excel** to analyze sales performance, profitability, customer segments, markets, products, and order returns.

## Dashboard Preview

![Sales Analysis Dashboard](Dashboard.png)

## Project Overview

This project provides an interactive view of sales performance using the Superstore dataset. The dashboard allows users to explore sales, quantity, delivery performance, returns, customer segments, markets, and product profitability through interactive visualizations and filters.

## Tools & Technologies

- **Power BI** – Dashboard development and data visualization
- **Excel** – Dataset and data preparation
- **DAX** – KPI calculations and measures
- **Power Query** – Data transformation and preparation

## Key KPIs

- Total Sales
- Total Quantity Sold
- Average Delivery Days
- Returned Orders
- Sales by Segment
- Sales by Market
- Product Profitability

## Dashboard Features

- Interactive year filtering
- Sales analysis by customer segment
- Sales analysis by market
- Top customers by sales
- Top products by profit
- Bottom-performing products by profit
- Delivery performance analysis
- Return order analysis
- Interactive Power BI visualizations

## Dataset

The project uses the **Superstore sales dataset**, containing order, customer, product, sales, profit, shipping, and regional information.

The dataset includes:

- Order information
- Customer information
- Product information
- Sales and profit
- Shipping details
- Geographic information
- Returns data

## How to Use

1. Download or clone this repository.
2. Open `Sales Analysis Dashboard.pbix` using **Power BI Desktop**.
3. If required, update the Excel data source path to point to `Superstore_Data_2016.xlsx`.
4. Use the interactive filters and visualizations to explore the sales analysis.

## Key Areas of Analysis

### Sales Performance
Analyzed sales across different years, markets, customer segments, and product categories.

### Profitability
Compared product and sub-category profitability to identify high- and low-performing products.

### Customer Analysis
Analyzed customer segments and identified customers contributing significantly to overall sales.

### Delivery & Returns
Examined average delivery performance and return orders to provide additional operational insights.

## Project Outcome

The dashboard provides an interactive view of sales and profitability performance, helping users identify important trends across customers, markets, products, and operational metrics.
